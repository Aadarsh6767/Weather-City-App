🌤️ Weather App

A lightweight, responsive web application that displays real-time weather information for any city worldwide using the WeatherAPI service.

🚀 Live Demo
https://aadarsh6767.github.io/Weather-City-App/

 Features
Real-Time Data: Fetches current temperature (°C), weather condition, humidity, and wind speed.
Dynamic Icons: Displays the official weather icon corresponding to current conditions.
Responsive Design: Clean, centered card layout optimized for mobile screens, tablets, and desktop displays.
Error Handling: Gracefully handles invalid city inputs and network issues.
Keyboard Friendly: Press `Enter` to search instantly without clicking the button.

 Built With
HTML5: Semantic structure
CSS3: Flexbox, modern variables, and responsive layout
JavaScript (ES6+): Fetch API, async/await, and DOM manipulation
API: [WeatherAPI](https://www.weatherapi.com/)
